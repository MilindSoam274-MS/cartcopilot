# Contributing to CartCopilot

Thank you for your interest in contributing to CartCopilot.

CartCopilot is a microservices-based conversational AI assistant that demonstrates how LLM orchestration can interact with real backend systems such as carts, product catalogs, and checkout workflows.

## How to Contribute

If you'd like to improve the project:

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Submit a pull request

## Contribution Areas

Contributions are welcome in the following areas:

- Improving retrieval accuracy
- Enhancing conversational flows
- Observability improvements (Prometheus/Grafana)
- Performance optimizations
- Additional AI tools or workflows

## Coding Guidelines

- Keep services modular and isolated
- Maintain clear separation between AI orchestration and backend logic
- Document new features clearly in the README

## Reporting Issues

If you find bugs or have feature suggestions, please open an issue in the repository.

Thank you for helping improve CartCopilot.
